# Contributing

Thanks for helping grow the Orbit Garden universe.

## Setup

    npm install
    npm run dev

Before opening a pull request, run:

    npm test
    npm run build

## Guidelines

- Keep TypeScript strict and avoid a UI framework for small additions.
- Keep data and pure logic separate from DOM rendering.
- Add tests for new catalogue or filtering behavior.
- Keep illustrations original, self-contained, and consistent with the SVG guide.
- Respect keyboard access and reduced-motion settings.
- Document any new remote service, script, or data collection.

## Pull requests

Describe the user-visible change, list validation commands, and include screenshots for visual changes. Small, focused pull requests are easier to review.
