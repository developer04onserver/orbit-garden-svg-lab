# Security policy

## Supported version

The latest default branch is the only supported version while the project is pre-1.0.

## Reporting

Do not post exploitable details in a public issue. Use GitHub private vulnerability reporting where available, or contact the repository owner through GitHub. Include affected files, reproduction steps, and likely impact.

## Security posture

Orbit Garden is a static front-end project. It does not collect credentials, store personal data, or make application API requests. Do not add dynamic code evaluation, unsanitized HTML rendering, or remotely hosted scripts.
